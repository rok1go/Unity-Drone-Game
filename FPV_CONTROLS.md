# FPV дрон

Открой `Assets/Scenes/Main/Main.unity`, нажми Play, затем Tab и щёлкни по Game View.

## Управление

| Клавиши | Действие |
| --- | --- |
| W / S | Наклон вперёд / назад (тангаж) |
| A / D | Наклон влево / вправо (крен) |
| Мышь влево / вправо | Поворот самого дрона вокруг вертикальной оси |
| Мышь вверх / вниз | Только наклон камеры, без тангажа корпуса |
| C | Вернуть камеру вперёд |
| Space / Ctrl | Подъём / снижение; отпустил — удержание высоты в ANGLE |
| V | Переключить ANGLE / ACRO |
| B | Включить / выключить моторы |
| H | Показать / скрыть подсказки |
| F | Подрыв с отсчётом |
| Tab | Переключить человека и дрон |
| R | Вернуть дрон на старт |
| Esc | Освободить курсор; полёт продолжается |

На клавиатуре в ANGLE Space задаёт подъём, Ctrl — снижение. После отпускания
дрон тормозит по вертикали и возвращается к высоте отпускания. Наклон компенсируется
увеличением тяги в пределах мощности моторов. Газ больше не накапливается.
Метка на шкале обозначает тягу висения горизонтального дрона (около 42%).
Горизонтальная инерция сохраняется: для торможения наклоняйся в обратную сторону.
В ACRO Space даёт полную тягу, Ctrl убирает её, нейтраль возвращает газ висения;
автоматического удержания высоты в этом режиме нет.

В ANGLE отпускание стика выравнивает корпус. В ACRO стик задаёт угловую скорость:
нейтраль прекращает вращение, но сохраняет наклон. Начинай с ANGLE.

Ввод вперёд/вбок ограничен по общей длине: диагональ не усиливает разгон.
В ANGLE общий наклон ограничен 30° по умолчанию. Плавность задаётся параметром
`Tilt Input Smoothing` (0,18 с по умолчанию); он сглаживает нажатие и отпускание.

При передаче управления человеку моторы дрона выключаются, он падает и остаётся
физическим объектом. При возврате моторы включаются с газом висения. Если дрон
лежит вверх ногами, используй R.

## Геймпад

Mode 2: правый стик — тангаж/крен, левый — газ/рыскание. Вертикальная ось газа
задаёт абсолютное значение от 0 до 100%, центр — 50%. A / Cross включает моторы,
X / Square переключает режим, Y / Triangle запускает подрыв. R и Tab доступны
с клавиатуры. Газ геймпада начинает действовать после движения стика.

## OSD

Скорость показана в км/ч, высота — над ближайшей поверхностью под дроном,
вертикальная скорость — в м/с. HOME — горизонтальное расстояние до старта.
Таймер считает время включённых моторов. Искусственный горизонт учитывает
текущий поворот камеры, компас показывает курс корпуса дрона. Это реальные
показания сцены; фиктивного заряда батареи нет.

Настройки доступны в `DroneController`: максимальный наклон, отношение тяги к весу,
угловые скорости, экспонента стиков, чувствительность мыши, угол и FOV камеры.
